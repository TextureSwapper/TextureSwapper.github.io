GET STARTED

01

02

FAQ

Frequently Asked Questions

Is Texture Swapper safe to use?

The Texture Swapper is safe to use. It modifies local client cache files only and it never touches game executables or server data. All visual changes are 100% client-side and visible only on your machine.

Which ProTanki clients are supported in v4.0?

Both! v4.0 introduces full HTML5 client support (alongside the existing Flash client). You can switch between them anytime in Settings.

How do I revert back to the original game textures?

Close ProTanki, open Texture Swapper, and click Restore Originals from the Backup History window. Your backed-up original cache files are restored cleanly.

What are the system requirements?

Windows 10 or Windows 11 (64-bit), the .NET 8.0 Desktop Runtime, and an official ProTanki client installation.

Can I test Premium features before buying?

Yes! You can activate a free 3 days trial directly inside the Settings window in the app with no credit card required.
